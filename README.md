# 📧 Spam Detection ML Classification Project

This project is developed for the Alfido Tech AI/ML Internship.

## 🚀 Features

- Data preprocessing
- Spam vs Ham classification
- Logistic Regression model
- Random Forest model
- Accuracy comparison
- Confusion Matrix
- ROC Curve
- Flask API deployment

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Flask
